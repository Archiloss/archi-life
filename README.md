## 关于这款游戏

你是刚出分的高中毕业生。分数随机，录取线也随机——同一所学校，两次的运气不一样。

之后五年，你只有三样东西：

| 数值 | 是什么 |
| --- | --- |
| **技能** | 硬功夫：画得出来、改得动、说得清 |
| **头发** | 你的本钱。熬的每个夜都在花它，花光了故事会在半路结束 |
| **作品** | 你攒下的东西，决定毕业时哪些门肯开 |

它们不会一起涨。加了这一样，另一样常常要还。

评图、答辩、毕设是三道关卡，过不过看技能够不够。走完五年，七条线分岔：
考研 / 留学 / 设计院 / 甲方 / 体制 / 转行 / 设计师工作室。
每条线有自己的卡组和落点，结局只给称号，不给排名。

面向建筑行业从业者，和已经转行的人。

## 特色

**界面是 AutoCAD。** 命令行、图层树、UCS 坐标轴、右下角状态栏，一样不少。
选项可以点，也可以直接敲字母，敲下的字母会在命令行里回显。

**骰子只管你控制不了的事。** 录取线、评图老师的心情、行业周期——掷骰子。
能自己决定的事（报志愿、交不交图）不摇。

**不比人。** 没有胜负，没有排行榜。48 个结局收在图鉴里，跨局累积。

**钱照实写。** 设计院月发 2740 这种事不回避。写得准，不拿来当笑话。

**零素材、零依赖。** 所有图形是代码画的 SVG，没有一张图片素材。
单个 HTML 文件约 480KB，双击就能开，手机和微信内置浏览器都能跑。

## 玩法

一局 10~15 分钟，一个人玩，或者几个人凑一台电脑轮流做决定。手机浏览器上也能玩。
结局图鉴存在浏览器本地，换一局不清零。

## 技术栈

原生 HTML + CSS + JavaScript，没有框架、没有构建依赖、没有外部请求。

刻意用老语法写（`function` 声明为主），为了在旧版手机浏览器和微信内置浏览器里
都能跑。源码拆成 `src/`，由 `build.py` 合成上面那个单文件。
